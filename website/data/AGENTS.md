# Generated website data instructions

- Files in this directory are generated publication inputs. Do not edit snapshots by hand.
- Every snapshot must identify schema version, generation time, repository, source hash, newest live update, and fallback state.
- Never include credentials, full issue bodies, comments, logs, attachments, private diagnostics, or guest data.
- A closed issue never implies a passed acceptance gate.
- Partial dependency graphs are invalid and must not be published.
- Schema changes require focused fixtures, tests, and an explicit clean-break decision while no external consumer exists.
