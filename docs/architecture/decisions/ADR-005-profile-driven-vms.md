# ADR-005-profile-driven-vms — Profile-driven direct-kernel and UEFI VMs

Status: Accepted for MVP scaffold

## Decision

Distribution and boot assumptions live in validated profiles. Qualify Alpine direct, Ubuntu UEFI, and K3s-lab profiles.

## Consequences

Implementation must satisfy the relevant module dependency rules and acceptance ledger. Reversal requires an ADR update plus migration/test plan.
