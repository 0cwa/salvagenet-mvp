# Post-MVP roadmap

- replace controller capability auth with reviewed mTLS/principal authorization;
- TUF and OCI/ORAS artifact distribution;
- strong QEMU process/UID isolation and arbitrary image threat model;
- multiple installed/active VMs;
- additional Ubuntu/Debian/Alpine cloud profiles;
- actual K3s worker provisioning and cluster qualification;
- Docker/Swarm reference provisioning;
- Device Owner and patched Android reliability tiers;
- AVF backend behind the runtime contract;
- Rust `phonectl`, Slint fleet controller, and Linux/SBC/WSL `hostd`;
- Nebula or another second mesh provider;
- remote profile repository and delegated profile maintainers;
- USB MVP+ hardening and artifact transport;
- web UI through a local controller bridge.
