# T07 experiment notes

This page is owned by task T07. Record only measured results, exact commands,
inputs, outputs, and blockers. Promote durable conclusions to an ADR or the
shared experiment register during integration.

## Results

- Enrollment recovery state is AES-GCM encrypted with an Android Keystore key
  in app-private preferences. Restart tests inject failure after every durable
  phase and verify convergence without a second authority acceptance or loss of
  the initial desired generation.
- Recovery SSH uses a random typed loopback host-forward allocation per service
  composition. Allocation probes at most 16 candidates in ports 20000-60999;
  a deterministic pre-bound collision test verifies bounded retry.
- Guest bootstrap remains on loopback port 8080 because the current public
  NoCloud callback and metadata contract pins `10.0.2.2:8080`. Binding is
  loopback-only and an occupied port now fails service creation immediately
  with an explicit contract error. This is defense-in-depth fail-closed
  behavior, not a claim that fixed-port allocation is generally safe.
- Cancel receipts retain all 256 idempotency results. Since no contract-defined
  expiry permits safe pruning, receipt 257 fails deterministically rather than
  evicting replay history.
