# T00 experiment notes

This page records measured T00 import, wiring, build, and hardware evidence.
Durable QEMU constraints remain in
`docs/architecture/qemu-command-knowledge.md`.

## Import provenance

- Lock repository: `https://github.com/ExTV/Podroid.git`
- Lock commit: `8ecfefaa3459b7e84c3d6e52c57e8005e289e8e3`
- Upstream and squash tree: `6c351c35b78fb7204e0dcb89c410cde2bb6cc291`
- Import command: `make import-podroid`
- The host initially lacked the optional `git-subtree` command. A Fedora
  `git-subtree-2.55.0-1.fc44.noarch` RPM was downloaded and extracted under
  `/tmp`; its executable was prepended to `PATH` for the import. No host package
  was installed and no repository file was changed for this workaround.
- Before workspace wiring, all three of `FETCH_HEAD^{tree}`, the subtree squash
  commit tree, and `HEAD:android/podroid` resolved to the tree above.

## QEMU argv capture

`tests/qemu/podroid-baseline.argv` is a one-element-per-line expansion of the
imported `QemuEngine.buildCommand`. The deterministic capture inputs select two
vCPUs, 512 MiB RAM, SSH enabled, repository-default extra arguments, and all
three forwards added by `PodroidService` (SSH plus loopback-only VNC/audio).
Absolute native-library/files paths and the detected Android IPv4 are normalized.
Inputs and conditional exclusions are machine-readable in
`tests/qemu/podroid-baseline.metadata.json`.

Notable corrections to the pre-import research fixture are the actual default
CPU/RAM values, both default argument override groups, the complete kernel
command line, VNC/audio forwards, terminal/control/host sockets, and Podroid's
actual socket names.

## Build and wiring results

Environment for checks:

- `JAVA_HOME=/home/kyvernitria/.local/nodehost/jdk-17`
- Java: Temurin OpenJDK `17.0.20`
- `ANDROID_HOME` and `ANDROID_SDK_ROOT`: `/home/kyvernitria/Android/Sdk`
- Gradle installed NDK `28.2.13676358` and Android platform `36.1` through the
  SDK manager during configuration/build.

Measured results:

- `./gradlew projects`: success; app, three upstream projects, and all eight
  base-MVP NodeHost sibling projects were present exactly once.
- `./gradlew :app:testDebugUnitTest :app:assembleDebug`: success, 224 actionable
  tasks (149 executed, 75 from cache).
- Debug APK: `android/podroid/app/build/outputs/apk/debug/app-debug.apk`, about
  40 MiB, SHA-256
  `675d60f407ef745e4a6dc48681ce860fdd9d322c61c68dae8a7045efd993ffa0`.
- Build warning: upstream manifest explicitly sets `android:extractNativeLibs`;
  this is intentional baseline behavior needed for executable native QEMU.

Additional non-required suite observations:

- `make test-jvm` reaches the sibling modules but fails in pre-existing
  `OperationTransitionsTest`: JUnit reports
  `terminalCannotRestartSilently() should be void`. The test source is outside
  T00 ownership.
- `make test-android` runs adapter tests but `:app:lintDebug` reports 22 imported
  upstream lint errors and 76 warnings. The required app unit test and assembly
  still pass. Broad upstream lint cleanup is not part of baseline import.

## Hardware evidence

`adb devices -l` reported no attached devices. Physical ARM64 boot, launcher
lifetime, Unix-socket behavior, and 16 KiB device alignment therefore remain
unmeasured in T00.
